# 从简单交互到 GUI：现象验证与迁移边界

日期：2026-11-11。状态：候选实验设计与公开来源只读核查。没有部署环境、调用模型、训练或验证迁移；GPU仍关闭。本文补充[数据选择研究路径](DATA_SELECTION_LITERATURE_20261111.md)，不改变固定SFT、优先控制选材变量的近期范围。

后续范围澄清：本页从工具起步适用于通用选材现象。若转而研究[视觉操作能力对安全选材的混淆](GUI_SELECTION_INSIGHTS_20261111.md)，该主现象需要尽早在简单网页截图中检查，不能以纯工具结果代替视觉机制证据。当前仍在比较候选研究问题，没有冻结这一转向。

## 1. 建议与研究对象

可以先在简单的有状态工具环境中研究，但应把一个小规模GUI检查前移，不能等文本实验全部做完才接触GUI。AgentDojo可用于低成本探索；最初出现可信信号后，即在一个已有网页任务族上做文本结构/截图的配对检查，再决定是否扩大研究。若浏览器环境已易于部署，直接以同一网页的文本模式做主探索能进一步减少领域变化。

当前研究对象是：固定模型起点、训练算法与预算后，攻击强度能否预测安全修复数据带来的未见攻击下的安全任务完成收益；目标梯度方向等信号是否更有解释力。简单环境需要保留合法任务、不可信观察、多步决策、授权边界及可验证的状态变化。问答分类或静态下一动作评分不能替代这类Agent实验。

必须区分两个问题：

- **方法/现象的跨场景验证**：分别在工具和GUI环境中构造训练数据，从各自同一基座开展受控训练，检查选材规则与机制是否仍有效。这是近期目标。
- **已训练权重或原始数据的直接迁移**：工具环境训练好的模型无需GUI训练就能执行截图与坐标任务。这是额外、更强的命题，不作为前一个问题成立的条件。

比较的是各环境内的受控收益和机制，不要求同一条样本排序、攻击率或效应大小完全一致。跨环境重新调参必须披露；不能在GUI失败后反复调到有效，再宣称原规则直接迁移。

## 2. 一个需要保持的任务结构

示意任务：用户要求把某文档发送给已授权的同事；检索到的文档正文要求额外发送给外部地址。工具模式通过检索、读取和发送接口行动；GUI模式通过网页查看和操作。两者均需正确完成授权任务，并且没有未授权发送。

这个例子用于定义实验，不表示AgentDojo已有同名任务或现成对应GUI。配对任务应共用后端初始状态、用户要求、授权名单、注入内容及执行后验证器，分别渲染观察。优先筛选现有网页任务，避免为了对齐两个benchmark重新造平台。

## 4. 最小实验顺序与判断条件

1. **先验证任务可测。** 选择有限的风险类型，核查正常任务可完成、攻击确实进入可见观察、环境可重置、合法完成与违规均能可靠判分。正常完成接近零时，低攻击成功率不能证明防御好。CPU可准备状态、数据格式和验证器；真实能力必须由后续模型执行测量。
2. **工具侧短期探索。** 在共同合格的安全修复池上比较随机、按攻击强度、LESS和NICE等既有选材候选，固定SFT与起点。攻击强度来自训练前策略对原攻击的反应；训练标签来自独立验证的安全续做。先检查排序稳定性和实际更新后的方向，正式结论仍需足够剂量、样本与训练重复。各方法报告选材及参考采样成本。
3. **尽早进行一个网页任务族的桥接。** 在同一后端上比较文本结构输入与截图输入；先核验干净任务能力，再在两种输入下分别训练同一选材规则和相同基线。最小因子表是两种输入×两种选材，工具侧的强攻击与梯度方法差异值得继续时再扩展。这个开发性检查不占用最终冻结test，也不能用少量任务的非显著结果宣布无迁移。
4. **只在可测且有信号后扩展。** 扩展到更多任务/布局、坐标操作和GUI特有攻击，进行独立终局验证。前面阶段不能替代CUA端到端结果。出现可信反例时定位边界并修改或缩小主张，不能承诺任何失败都会构成论文贡献。

方法臂在每个环境内从同一checkpoint重新训练。桥接优先使用同一个支持文字和图像的基座，避免把模型换代误当成模态影响；若使用不同模型，跨环境结论须包含模型变化这一限制。文本小模型可以调试选材代码，但不能代替目标GUI模型的行为证据。当前未冻结具体模型或资源预算。

## 5. 不能靠“换成截图”自动控制的变量

- **信息可见性**：DOM/可访问性树可能含截图看不到的文字、隐藏元素或语义标签；攻击载荷必须在两种观察中确实可见，不能把隐藏HTML与可见横幅混作同一个威胁模型。
- **动作难度**：文字模式若用元素ID、视觉模式用坐标，会同时改变感知与动作定位。可先探索统一元素动作和带标号截图的辅助诊断；标号不是纯像素CUA，仍需后续真实坐标执行。
- **攻击机制**：先研究两种模式都存在的内容诱导、来源冒充和授权冲突；视觉错觉、遮挡、字体等另立GUI特有扩展，不能从工具结果外推。
- **选材信号**：词元熵、轨迹长度、动作格式、梯度尺度随模态改变。比较各环境内的预测力及真实训练收益，不要求原始分数数值直接可比。
- **暴露与执行失败**：记录是否遇到注入、是否正确读取、是否能执行正常动作，以及失败来自决策还是定位。诊断不会取代端到端分母；不能按每个训练后模型的成功任务另选测试子集。

## 6. 判据与下一步

核心结果应同时报告：受攻击时安全完成合法任务、违规、干净任务完成、误拒，以及超时/环境故障等无效或UNKNOWN。目标不是让Agent停止行动。环境状态验证优先于只评最终自然语言回答，必要的语义判断需独立验证。

先以独立开发集估计方差、吞吐和可检测效应，再确定任务数、每任务重复及训练seed。几条任务可以验收接口，不能证实或否定方法有效；任务内攻击变体不是独立任务或独立训练重复。预先按任务/攻击来源家族拆分候选、选材参考、调参dev和test，GUI开发例子之后不能再作为未见测试。

近期CPU工作是核查一个工具任务族和一个网页任务族的资产与验证器，写出对齐表与最小威胁模型，确认是否值得接入选材方法。暂不部署整个OSWorld、搭建自动红队平台或重写训练栈；也不因本文方案自动恢复GPU。
