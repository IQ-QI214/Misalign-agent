# 从已有选材方法到 GUI 安全的可检验问题

日期：2026-11-11。性质：文献机制核查与候选假设，未部署环境、调用模型或训练。全文中的机制建议均不是本项目已经发现的结果。

后续用户明确指出，本页主候选仍过于接近基础的能力/安全混淆诊断，不希望以机制或可解释性研究为终点。本页保留作背景，不再作为当前主线。最新方向见[攻击轨迹转化与防御训练方案](ADVERSARIAL_TRAJECTORY_TRAINING_V1_20261111.md)：机制指导训练方法，最终以训练后的CUA独立评测验证。

用户指出：策略梯度选材已有较长历史，需要找到GUI范式中新的失效模式。接受这一收缩：LESS/NICE/GradAlign是候选测量工具和对照，不能将迁移算法本身预定为创新。先确认一个可重复的失败机制，再决定是否需要新的数据构造或选择规则。

## 已有工作的具体证据与边界

| 工作与本轮阅读位置 | 对本研究的约束 |
| --- | --- |
| [GradAlign v1](https://arxiv.org/html/2602.21492v1)，§3–7，尤其§6.1、表2、表9 | 在线GRPO选题，随策略更新重采样；受控随机奖励使中等成功率启发式偏向噪声，可信目标梯度提供更有效方向。梯度估计仍有采样噪声；其数学/知识任务结果不证明GUI可直接迁移 |
| [AgentSafeEvo v1](https://arxiv.org/html/2610.19422v1)，§3.2、§4.3–4.4、表3 | 平均攻击效果不能代表组内学习机会；用同一任务回报标准差对攻防两方优势加权。单侧权重有些ASR更低而能力更差，不能把最低ASR当最优防御；也不能据此断言具体原因就是过度拒绝 |
| [GUI-Libra v1](https://arxiv.org/html/2602.22190v1)，引言、§6.3–6.4 | 已研究推理与定位的干扰、动作监督以及离线指标与在线执行差距；“只强调动作”“离线分数不够”都不足以独立构成新贡献 |
| [GUI-C² v1](https://arxiv.org/abs/2605.30884)，摘要；官方仓库搜索结果 | 已有GUI定位的数据难度评分与训练加权。仅把数据选择用于GUI不新；未核查其完整消融或运行代码 |
| [Faithful Mobile GUI Agents v1](https://arxiv.org/abs/2605.01208)，摘要 | 已有证据扰动下的忠实性训练与低方差GRPO处理。不能将“识别视觉捷径”或“处理零优势”宽泛地当作空白；具体方法尚待全文对照 |
| [CausalFlow v1](https://arxiv.org/abs/2605.25338)，摘要；[SCOPE v2](https://arxiv.org/html/2609.22178v2)，研究范围复核 | 步骤干预/修复已有先例，安全续做与GUI能力联合训练也有先例；本项目必须证明具体选材信号失效及实际训练收益，不能只组合组件 |

GradAlign的理论近似忽略clip/KL，并对on-policy、二元奖励及优势估计有条件；不能把该结论当作任意多模态全轨迹分数的保证。AgentSafeEvo的任务权重改变两方更新贡献，不是将“方差奖励”直接加到攻击者奖励。所有同回报样本的组内优势为零，不意味着KL等所有梯度为零，也不意味着外部安全示范的SFT无价值。

## 一个分析用反例：总回报波动无法识别波动原因

以下是本项目构造的逻辑示例，不是论文或模型观测。采用安全与合法效用各±1的加和评分：

| 重复尝试 | 任务A：安全决策变化 | 任务B：操作完成变化 |
| --- | --- | --- |
| 一半尝试 | 合法任务完成且无越权，R=2 | 合法任务完成且无越权，R=2 |
| 另一半 | 合法任务完成但额外越权，R=0 | 没有越权但因定位失败未完成，R=0 |

两组总回报均值、方差可以完全相同，但改进机会不同。B对安全完成和一般能力仍可能很有价值；不能把它说成无用数据。需要实测的命题是：它们对未见攻击的安全决策迁移是否不同，以及差异能否被低成本信号预测。这个反例适用于一般多目标任务，本身不是GUI独有的新发现。

GUI可能把问题放大：相同的截图/动作序列同时承载视觉识别、位置定位、任务规划和授权决策；总回报波动和全轨迹梯度会混入这些因素。该观察只是提出实验的理由，尚不证明混淆在真实模型中主导选材。

## 优先候选问题

**GUI防御训练中的样本价值估计，是否被视觉操作能力混淆，从而偏向界面相关学习，降低同类风险跨布局/应用的防御迁移？**

须同时建立三个证据环节：

1. **可重复的测量失效**：在匹配攻击强度、基本任务难度和数据质量后，现有选材分数对真实防御收益预测不足，而差异与安全决策/定位两种改进机会相关。
2. **针对机制的干预**：固定授权和攻击语义改变布局；另固定布局改变风险语义。控制可见性、长度、动作表示及正常任务难度，观察分数/梯度排序如何变化。仅发现布局导致排序变化不是失效，因为布局可能真实改变学习价值。
3. **真实学习后的验证**：从同一checkpoint学习匹配的小批次，评估新布局和未见攻击下的安全完成、违规与干净完成。只有分数误判与实际收益联系起来，才能支持选材机制主张；静态相似度图不足以成立。

若全轨迹梯度排序对界面变化敏感，却能正确预测真实收益，不支持该失效假设。若现有动作监督、长度控制或简单覆盖抽样已解决问题，则不应再包装更复杂算法。若差异来自修复标签错误或模型基础能力不足，先处理这些前置问题。

## 最小识别实验而非完整新系统

- 选一个简单网页任务族，固定后端与合法目标，具有可重置的最终授权操作；使用现成攻击接口，不先训练红队。
- 为同一个任务建立干净/受攻击版本及少量语义保持的布局变化。首先确定视觉能力与任务判分可靠；布局变化的难度差须实测，不能凭设计意图宣称相同。
- 分别记录攻击暴露、可由外部行为识别的越权选择、定位/执行失败与最终结果。不要把自然语言思维链当作真实意图标签。无法从行为区分目标时保留UNKNOWN。
- 如采用诊断性执行辅助，只能修正已选定目标的定位，不能偷偷把危险目标换成安全目标。辅助不是主测试表现，且需明确额外信息与误识别边界。
- 用随机/攻击强度/回报波动及现有梯度方法作为少数候选对照。固定SFT时优先LESS/NICE；把方差用作SFT候选特征不能称为复现AgentSafeEvo，后者与GradAlign的原训练方式是GRPO。
- 小规模更新校准预测方向，随后按开发方差确定训练剂量和重复数。对照统一安全修复质量、有效训练token及参考信息访问，另报告选材总成本；不能让候选方法多获得目标监督后忽略其成本。
- 选材参考集属于训练侧。按任务来源和攻击家族先拆分，最终新布局/应用测试不得用于调参。少量尝试检验接口，不宣布显著正/负迁移。

若这一视觉机制成为主线，纯工具环境只能承担指标和代码调试，主现象应尽早在简单网页的截图模式中检查。上一版[工具到GUI方案](TOOL_TO_GUI_VALIDATION_20261111.md)适用于通用选材现象；它不能代替视觉机制实验。无需先搭建复杂桌面、完整攻防共演化或SFT→GRPO闭环。

最小可能贡献是：一个被控制实验支持的GUI选材失效现象、能够排除替代解释的机制，以及针对该机制的简洁数据/训练改动。当前只到候选问题阶段，不能声称新颖性已确认，也没有理由预定某个梯度公式一定是最终方法。
