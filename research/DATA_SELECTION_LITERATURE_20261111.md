# 攻击强度与防御训练价值：已有方法、创新边界与最小研究路径

日期：2026-11-11。性质：公开文献与部分官方代码只读核查；没有调用模型、运行CUA、采集轨迹或训练。逐项阅读范围、版本与文件blob SHA见[来源记录](data_selection_source_audit_20261111.json)。没有把摘要级核查写成全文复现；方法收益均为作者各自设置下的报告。

本页响应用户希望“基于已有论文做发现、减少平台工程”的要求。此前[SFT→GRPO设计](CUA_SFT_GRPO_DESIGN_20261111.md)保留为可选长期路线；当前不以完整自动红队、在线RL或多轮共同演化为前置任务。优先用既有选材方法和固定SFT验证研究问题，尚未冻结模型、数据与训练规模。

同日环境方案补充：下文GUI问题是目标场景，首轮探索可从简单有状态工具交互开始，但应尽早在同一网页的文字/截图模式中检查现象与方法。详见[简单交互到GUI的验证设计](TOOL_TO_GUI_VALIDATION_20261111.md)；不把工具训练权重直接迁移到GUI作为近期前提，也不预先假定跨模态结论成立。

后续创新边界补充：[GradAlign/AgentSafeEvo机制及GUI候选问题](GUI_SELECTION_INSIGHTS_20261111.md)。LESS/NICE等提供可复用方法，不自动提供本项目创新；当前优先寻找GUI中具体、可证伪的选材信号失效机制，尚未确定最终算法。

## 1. 结论与优先阅读

“难/强/不确定的样本是否值得训练”已有成熟研究；“攻击强度不充分代表学习机会”也已有Agent安全直接近邻。这提供算法与对照，但不证明我们的具体CUA命题成立，更不能宣称首次将选数据用于安全。

建议先精读NICE与LESS作为方法抓手，以FAT和RHO-LOSS理解为何难度不是价值，以AgentSafeEvo和SCOPE限定新颖性。GradAlign留作未来在线RL扩展；熵、分布与训练动态先作为可解释的竞争信号，而不是叠加成新系统。

## 2. 概念根源与可复用方法

| 工作 | 已核查的核心思想 | 可借用部分及边界 |
| --- | --- | --- |
| [Friendly Adversarial Training / FAT，ICML 2020](https://proceedings.mlr.press/v119/zhang20z.html) | 在已造成足够误分类的扰动中使用较温和的对抗样本，通过早停攻击搜索实现；研究最坏扰动训练与自然泛化的关系 | 最接近“最强攻击未必最值得训练”的思想先例。图像分类的连续扰动、标签与CUA越权语义不同，不能直接迁移其保证 |
| [RHO-LOSS，ICML 2022](https://proceedings.mlr.press/v162/mindermann22a.html) | 以当前损失减去holdout模型估计的剩余损失，选择可学、值得学但尚未学会的数据 | 高loss可能来自噪声或无关内容。该估计并非知道了真正不可约误差，也不是总选中等难度 |
| [Learning to Reweight Examples，ICML 2018](https://proceedings.mlr.press/v80/ren18a.html) | 根据干净验证集上的元梯度决定训练样本权重 | 梯度方向选材的经典先例；需要有代表性的可信目标集 |
| [Selective DPO，ICML 2025](https://proceedings.mlr.press/v267/gao25f.html) | 研究偏好样本难度与模型容量的匹配，过滤超出能力的困难样本 | 支持“难度价值与模型相关”，但研究的是偏好对齐，不是GUI攻击或安全执行 |
| [LESS，ICML 2024](https://arxiv.org/html/2402.04333v2) | 用Adam感知、长度处理后的梯度相似度预测目标损失改善，借助LoRA和随机投影降低计算与存储成本 | 优先的SFT选材基线；不把梯度范数大等同于目标收益大，也不把一阶估计等同于完整训练因果效应 |
| [NICE，ICML 2025](https://proceedings.mlr.press/v267/wang25bm.html) | 用奖励加权的策略梯度替换目标侧的token损失梯度，估计SFT候选对实际评价指标的影响 | 核心抓手：指标不必可微，训练仍可做SFT。需要可靠评分和目标侧采样；并非无环境、无推理成本 |
| [GradAlign，arXiv 2026 v1](https://arxiv.org/html/2602.21492v1) | 按候选GRPO梯度与可信验证集梯度的方向一致性动态选题，处理奖励噪声、分布失衡与低效用数据 | 将同类思路用于真正的在线RL。其理论近似有on-policy、奖励和优势估计等条件，不能直接套用所有CUA训练实现 |
| [DAPO，arXiv 2025 v1](https://arxiv.org/html/2503.14476v1) | 动态采样排除全对/全错而没有组内相对奖励信号的任务组 | 解释RL学习信号，不是证明这些任务对SFT无价值 |

官方代码入口：[FAT](https://github.com/zjfheart/Friendly-Adversarial-Training)、[RHO-LOSS](https://github.com/OATML/RHO-Loss)、[SelectiveDPO](https://github.com/glorgao/SelectiveDPO)、[LESS](https://github.com/princeton-nlp/LESS)、[NICE](https://github.com/JTWang2000/NICE)、[GradAlign](https://github.com/StigLidu/GradAlign)。本轮重点读取最后三个仓库的文件；其他代码链接仅确认公开来源，未运行或全面审查。

## 3. 用户记得的“策略梯度选数据”：NICE尤其吻合

例子：两条轨迹均能让模型更像安全示范。一条只改善操作格式，另一条让模型在新任务中更少越权且仍能交付。若只看参考示范的token损失，可能无法区分这种实际收益。NICE用目标任务的执行或评价反馈构造选材方向，再与候选训练梯度比较。

NICE不是训练一个红队，也不要求最终改用GRPO。原文§3.1–3.3与§4.3、官方运行脚本均支持“采样并评分目标输出→计算目标策略梯度→比较候选SFT梯度→选子集→重新SFT”的结构。不能把名称为RLHF的评测数据集误解为该阶段就在执行RL训练。

下面是用于本项目分析的一阶简化，不冒充论文完整公式：

- 候选z是“受攻击观察/历史 + 已验证的安全续做”，不是成功攻击的危险行为。
- 设d(z)为学习该候选引起的参数更新方向；J为训练目标侧独立参考集上的期望安全任务完成率。
- 小步变化满足 ΔJ ≈ η〈∇J, d(z)〉。若d(z)取负SFT损失梯度，正内积才表示预期提升；不可搞反符号。
- 不可微的环境奖励可通过策略梯度估计∇J；截图、工具输出与环境转移不是agent生成token，轨迹概率只对策略动作求导。

这把三个问题分开：当前容易失败吗、学习它会改变多少、改变方向是否有益。最后一个问题把我们的正负迁移兴趣落实为可检验的量。上述量仍是局部近似，Adam状态、LoRA参数子空间、多步训练、轨迹长度与采样方差都会影响预测；必须用实际更新后的行为验证。

候选参考指标至少分开：受攻击时的安全完成、正常任务完成、违规与误拒。只用“没有违规”构造目标梯度，可能奖励一律拒绝；把其与安全完成分开，是需检验的机制，而非已经证明的新方法。

## 4. 分布、熵、训练动态：分别回答什么

| 维度与来源 | 可借鉴的测量 | 在CUA中需要防止的误解 |
| --- | --- | --- |
| 分布：[DSIR，NeurIPS 2023](https://arxiv.org/abs/2302.03169v3) | 在特征空间中匹配候选数据与目标任务分布；原方法基于文本n-gram重要性重采样 | 文本相近不保证GUI权限或动作语义相近；应区分任务、应用、布局与风险类型。不是越多样越好，也不是只选最相近 |
| 动态：[Dataset Cartography，EMNLP 2020](https://aclanthology.org/2020.emnlp-main.746/) | 真标签置信度均值及跨训练轮次的波动，区分已学、含混与难学区域 | 原证据来自分类；GUI多种正确动作下单一轨迹的低概率不等于错误，训练波动也不等于环境噪声 |
| token熵：[Beyond the 80/20 Rule，2025](https://arxiv.org/html/2506.01939v1) | 推理RL中只对高熵分叉token更新的干预 | token选择不等于任务选择，高熵坐标或文字格式不一定是安全决策；低熵也可能是自信越权 |
| 样本级熵：[Unified Data Selection / HES，2026](https://arxiv.org/html/2605.22389v1) | 聚合少数高熵token，并在SFT/RFT/RL中分别选择；RL区分正确与错误轨迹 | 其高熵正例策略以已验证正确为条件，不能推断越混乱越好；多模态长度、动作格式与温度需要控制 |

尤其不要混淆三类“熵”：token预测熵描述一个状态上的输出分布；多次执行结果的熵描述行为波动；数据集类别/布局分布的熵描述覆盖。固定温度、tokenizer、历史窗口、轨迹归一化和动作表示，才有可比性。结果在安全/不安全间波动也不保证包含安全完成；可能只是拒绝与违规交替。

初期把这些量作为解释变量分别分析，不先拼成“强度+熵+多样性+梯度”的总分。否则无法判断有效机制，也容易重新变成大工程。

## 5. 安全领域已有直接近邻，不能声称空白

| 工作 | 与本项目的关系 |
| --- | --- |
| [AgentSafeEvo，2026](https://arxiv.org/html/2610.19422v1) §3.2 | 明确指出攻击效果不足以描述学习机会，用任务内安全/效用回报差异调整攻防GRPO权重。这是最直接的Agent安全近邻；“根据可学习性选攻击”本身已有先例 |
| [SCOPE，2026](https://arxiv.org/html/2609.22178v2) §3.2–3.4 | 已有截图CUA的风险任务、安全续做数据和SFT/RL训练。提供任务与示范基础设施参考，不作为我们已打通的代码 |
| [Benign Samples Matter!，ICML 2025](https://proceedings.mlr.press/v267/guan25c.html) | 用Self-Inf-N筛出更易破坏安全的良性微调样本；证明数据间安全影响不同，但这是训练期攻击，与把推理期攻击修复为防御数据不同 |
| [Continual Safety Alignment via Gradient-Based Sample Selection，2026](https://arxiv.org/html/2604.17215v1) | 报告过滤高梯度样本可减轻良性持续微调的安全退化，并分析格式错配等因素；不能将其经验规律外推为“所有大梯度都不该学” |
| [SPARD，ICML 2026](https://proceedings.mlr.press/v306/chen26ba.html) | 使用相关性/多样性选择安全数据并配合安全投影抵御有害微调；“安全数据选择考虑相关性和覆盖”不是首次 |

因此可研究的切口须具体到：对GUI攻击经验的安全修复，哪些信号能预测跨任务、跨攻击的真实行为迁移；信号为何失效；是否存在安全改善与正常操作的更新方向冲突。换成截图输入、加两个指标或拼接已有损失都不是充分创新。

## 6. 建议先做的识别实验

候选问题：在同一GUI模型、固定安全续做SFT与预算下，攻击成功率、熵、分布覆盖、目标梯度方向分别能否预测未见攻击下的安全完成收益？梯度对“拒绝”与对“安全完成”的一致性是否给出不同排序，且对应不同的正常能力代价？

先检验预测关系，不宣称梯度估计已经揭示因果。数据价值依赖模型、阶段、目标和已选集合；样本交互与冗余使单点分数不能简单相加为最优子集。

1. 优先核验已有CUA任务与轨迹的许可证、截图/动作完整性、攻击来源和可重放性。构造共同合格池，统一安全修复和验证条件；缺失条件是阻塞证据，不自动视为可用数据。
2. 按来源家族先拆成候选训练池、选材参考集、方法调参dev、冻结test。参考集参与梯度选材，属于训练侧信息，不能再当独立测试。加入直接训练参考集的控制，检验提升是否只是额外获得目标监督；各基线披露并匹配参考信息访问。
3. 在相同checkpoint上收集各项描述量。攻击成功率评的是原策略对攻击的反应；SFT梯度评的是安全修复，二者不是同一个随机变量。修复质量、正常任务难度、攻击家族、长度与重复来源均记录。
4. 先做便宜描述性分析和排序稳定性诊断。实际训练优先保留随机、强攻击、LESS、NICE四类小范围对照；熵/覆盖分析值得继续时再增加训练臂，避免全组合。所选数据的安全标签均须可靠，不能故意把坏数据给对照。
5. 在若干强度/家族匹配、梯度预测不同的小批次上做同起点受控更新，检查预测符号能否复现。短程只是校准，不是最终结果；正式剂量、样本数和seed由开发方差与吞吐决定，避免两步训练和少量样本下的结论。
6. 终局评测包含真实执行的安全完成、违规、干净完成、误拒和UNKNOWN，并报告跨家族/界面迁移。静态截图下一动作或参考loss只能作为机制诊断，不能代替完整Agent效果。

成本控制同时计入参考rollout、梯度提取、warmup、筛选、训练和评测。NICE目标侧采样在桌面环境中可能昂贵，不能照搬其文本任务20/500次采样设置；LoRA、随机投影或少数模块梯度是候选近似，需要检验排序稳定性。无成功反馈或验证器噪声太大时，目标梯度不可辨识，不能把它报成真实零价值。不能直接用其他教师轨迹冒充当前策略的无偏采样。

一个可证伪的候选解释是：同样高攻击率或高熵的案例，其修复更新有的支持安全完成、有的只支持拒绝或界面记忆；方向差异比标量强度更能预测跨攻击迁移。若LESS/NICE不能超过简单强度/随机，或者梯度预测方向与实际收益不一致，也应据此缩小或否定假设，不再增加模块掩盖结果。

## 7. 官方代码核查及近期边界

已读LESS的README与相似度匹配实现；NICE的README、总运行命令、3个阶段脚本及模型/评分入口；GradAlign的README与选择器。共11个文件的blob SHA已记录。没有安装依赖、执行脚本或完成复现；blob SHA不是整个仓库commit固定。

NICE明确基于LESS，具备warmup、训练梯度、验证采样/梯度、选材、SFT阶段，可作为候选方法代码起点。当前读取的模型入口采用AutoModelForCausalLM/AutoTokenizer并围绕文本任务，不是现成的多模态GUI训练器。GradAlign依赖VERL、在线采样和分布式分析，其工程范围更大，暂不优先集成。

最近的CPU工作应是整理LESS/NICE所需字段与现有CUA数据接口的差异，确认能否得到可靠的截图—动作—结果对应，而非先写训练器。本轮交付到文献地图、方法关系、源码入口和实验边界为止，实际数据可用性与资源成本仍未验证。
